# Goal of this subproject
The goal of this project is to extend the current snowprofiles dataset hosted on frdr with the data collected during the 2025-2026 field work campaign. Practically, the currently hosted data on FRDR will be updated with a new version of itself with the 2025-2026 year data

# Decisions (session 2026-10-02)
- Folder organization: one `datasets/{id}/` folder per FRDR record, for all versions. No new folder per version; git tags `{id}/v{N}` mark published states. Per-period subfolders in `raw_data/`, `frdr_data/`, `artifacts/`.
- Dataset extension is now a reusable workflow: see `steps/extension.md` (Step 0 Baseline + per-step deltas) and the "Extending a published dataset" section of AGENTS.md.
- 2024-2025 is not redone: the published v1 (DOI 10.20383/103.01634, published 2026-05-07) is downloaded as a read-only baseline into `published/v1/` and carried over unchanged.
- FRDR versioning: "New Version" copies previous files; new DOI per version; public summary of changes (max 2,000 chars). `frdr-dfdr-checksums.txt` is generated by FRDR, used only to verify the download, never uploaded.
- Normal update = upload the new data folder + the new README.txt. The first extension (flat -> per-period layout) uploads the whole `frdr_data/` with Globus "delete files absent from source".
- The 2025-2026 analysis on remote branch `rogerspass-2025-2026/scope-research-qc` (commit 44e55ec, separate-collection exercise) can be reused as input for Research / Explore / QC, re-run under the new instructions.
