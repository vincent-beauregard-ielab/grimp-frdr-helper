# GRIMP research metadata

This projects aims to assist GRIMP researchers in organizing, describing and sharing their datasets in compliance with FAIR principles (Findable, Accessible, Interoperable, Reusable) to the Federated Research Data Repository (FRDR).

It work is help by llm agents to automate the generation of metadata, inspecting the dataset content and structure, and retrieve relevant information from external sources and knowledge bases to enrich the dataset description.

## Components

### Helpers

Modules and skills to inspect the dataset content and structure, and generate metadata in compliance with FRDR requirements using LLMs.
